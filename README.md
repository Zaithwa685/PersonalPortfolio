# Zaithwa Nthala — Personal Portfolio Website

## Purpose of the Website
This website is my personal portfolio for my Computer Science assignment at DMI University. It introduces who I am, my academic background, my skills, and the projects I have built. It shows that I can design and build a complete, responsive website using HTML, CSS and JavaScript.

## Pages
1. **Home (index.html)** — Welcome, my name, my programme, my professional interests, my photo, and featured work.
2. **About (about.html)** — My background, academic background at DMI University, my skills, my goals and contact details.
3. **Projects (projects.html)** — My 3 projects: KUWALA, Auxano, and Inventory Control System, with GitHub links.
4. **Animated Concepts (animations.html)** — Demonstrates the animations I implemented: Hover Effects, Animated Background, and Animated Skill Indicators.

## Technologies Used
- **HTML** — Structure of all pages, navigation menu, tables, and content.
- **CSS** — Blue gradient background, floating shapes animation, hover effects, cards, layout, and responsive design for mobile.
- **JavaScript** — Animated skill bars that fill from 0% to 40% when the page loads.
- **GitHub Pages** — To publish the website online.

## Features
- Navigation menu on every page (Home, About, Projects, Animated Concepts)
- Floating animated circles on every page background
- Hover effects on buttons, photo and project cards
- Animated skill bars (HTML, Python, JavaScript — 40%)
- Responsive design — works on laptop and phone
- Profile photo and contact details
